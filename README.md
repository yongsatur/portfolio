# Портфолио

Создаю цифровую реальность: проектирую информационные системы и превращаю строки кода в программные продукты для решения различных бизнес-задач. 

## О себе

Разработала три веб-сервиса: [систему управления проектами для Министерства сельского хозяйства Забайкальского края](https://github.com/yongsatur/krst-zab), [сайт с интеграцией Google Drive для социологического факультета университета](https://yongsatur.github.io/zabgu/) и веб-приложение для студенческого спортивного клуба. 
Интересует профессиональное развитие в сферах системного анализа и разработки программного обеспечения.
