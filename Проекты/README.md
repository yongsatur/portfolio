## Сайт для приема заявок и статей

Разработала и внедрила [сайт для приема заявок и статей](https://yongsatur.github.io/zabgu/) в рамках выполнения заказа для социологического факультета Забайкальского государственного факультета. Его цель — упростить процесс регистрации участников и сбора научных материалов для конференции. Есть интеграция с Google Drive для хранения данных и файлов с использованием таблиц и облачного хранилища.
