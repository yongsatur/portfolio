# Проекты

Портфолио реализованных проектов. 
Синей звездочкой ($`\color{blue}*`$) отмечены проекты, прошедшие путь от идеи до запуска и внедренные в работу.

## $`\color{blue}*`$ Система для управления проектами 

[Система управления проектами](https://github.com/yongsatur/krst-zab) – заказная разработка для Министерства сельского хозяйства Забайкальского края. Система предназначена для управления проектами и данными в сфере агропромышленного комплекса региона.

**Стек технологий:**

$`\color{yellow}*`$ `Python` · `Django`<br>
$`\color{yellow}*`$ `HTML5` · `CSS3` · `JavaScript`<br>
$`\color{yellow}*`$ `Bootstrap 5`<br>
$`\color{yellow}*`$ `MySQL`

## $`\color{blue}*`$ Сайт для приема заявок и статей

[Сайт для приема заявок и статей](https://github.com/yongsatur/zabgu) – заказная разработка для социологического факультета Забайкальского государственного факультета. Его цель — упростить процесс регистрации участников и сбора научных материалов для конференции. Есть интеграция с Google Drive для хранения данных и файлов с использованием таблиц и облачного хранилища.

**Стек технологий:**

$`\color{yellow}*`$ `HTML5` · `CSS3` · `JavaScript`<br>
$`\color{yellow}*`$ `Bootstrap 4`<br>
$`\color{yellow}*`$ `Go`

## $`\color{blue}*`$ Платформа для спортивного клуба, 

Платформа для спортивного клуба – заказная разработка для студенческого спортивного клуба Забайкальского государственного университета. Она помогает облегчить процесс информирования студентов по секциям и спортивным залам, а также позволяет им записываться на секции и отслеживать собственную активность.

**Стек технологий:**

$`\color{yellow}*`$ `Python` · `Django`<br>
$`\color{yellow}*`$ `HTML5` · `CSS3` · `JavaScript`<br>
$`\color{yellow}*`$ `Bootstrap 5`

**Проектирование и моделирование:** по [ссылке](../Проектирование/Спортивный%20клуб) можно посмотреть процесс проектирования информационной системы.
